# Día 1: Fundamentos de IA y Machine Learning

Primer día del curso. Presentamos qué es la Inteligencia Artificial y cómo funciona el flujo de trabajo del Machine Learning, y construimos los primeros modelos con `tidymodels`.

## Sesiones

| Archivo | Sesión |
|---------|--------|
| `01-que-es-ia.qmd` | 1.1 ¿Qué es la Inteligencia Artificial? Historia, tipos de aprendizaje y ética básica |
| `02-fundamentos-ml.qmd` | 1.2 Fundamentos de Machine Learning: train/test, validación cruzada, métricas y sobreajuste |
| `03-laboratorio-01.qmd` | 1.3 Laboratorio 1: primer flujo de trabajo con `tidymodels` |
| `04-laboratorio-02.qmd` | 1.4 Laboratorio 2: validación cruzada y comparación de modelos |

## Archivos

- `NN-*.qmd`: diapositivas de cada sesión (la numeración es continua a lo largo del curso)
- `laboratorio-N.R`: el código del laboratorio N en un script de R
- `tarea-N.qmd` y `tarea-N-respuestas.qmd`: enunciado y clave de respuestas de la tarea N
- `datos/`: conjuntos de datos usados en las sesiones y los laboratorios

Las diapositivas renderizadas están en el [sitio del curso](https://danilofreire.github.io/introduccion-ia-ucu).
