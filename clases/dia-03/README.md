# Día 3: Texto y aprendizaje no supervisado

Tercer día. Agrupamos datos sin etiquetas con clustering y reducción de dimensionalidad, y damos los primeros pasos en el análisis computacional de texto.

## Sesiones

| Archivo | Sesión |
|---------|--------|
| `09-clustering-pca.qmd` | 3.1 Clustering y reducción de dimensionalidad: K-means y PCA |
| `10-analisis-texto.qmd` | 3.2 Análisis computacional de texto: tokenización, TF-IDF, sentimiento y LDA |
| `11-laboratorio-05.qmd` | 3.3 Laboratorio 5: clustering y PCA |
| `12-laboratorio-06.qmd` | 3.4 Laboratorio 6: análisis de texto |

## Archivos

- `NN-*.qmd`: diapositivas de cada sesión (la numeración es continua a lo largo del curso)
- `laboratorio-N.R`: el código del laboratorio N en un script de R
- `tarea-N.qmd` y `tarea-N-respuestas.qmd`: enunciado y clave de respuestas de la tarea N
- `datos/`: conjuntos de datos usados en las sesiones y los laboratorios

Las diapositivas renderizadas están en el [sitio del curso](https://danilofreire.github.io/introduccion-ia-ucu).
