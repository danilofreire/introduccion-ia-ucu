# Día 2: Aprendizaje supervisado

Segundo día. Cubrimos los principales algoritmos de clasificación y regresión, la diferencia entre predecir y explicar, y la regularización para evitar el sobreajuste.

## Sesiones

| Archivo | Sesión |

| `05-clasificacion.qmd` | 2.1 Métodos de clasificación: regresión logística, árboles de decisión y Random Forest |

| `07-laboratorio-03.qmd` | 2.3 Laboratorio 3: clasificación avanzada |
| `08-laboratorio-04.qmd` | 2.4 Laboratorio 4: regresión y regularización (LASSO, Ridge, Elastic Net) |

## Archivos

- `NN-*.qmd`: diapositivas de cada sesión (la numeración es continua a lo largo del curso)
- `laboratorio-N.R`: el código del laboratorio N en un script de R
- `tarea-N.qmd` y `tarea-N-respuestas.qmd`: enunciado y clave de respuestas de la tarea N
- `datos/`: conjuntos de datos usados en las sesiones y los laboratorios

Las diapositivas renderizadas están en el [sitio del curso](https://danilofreire.github.io/introduccion-ia-ucu).
