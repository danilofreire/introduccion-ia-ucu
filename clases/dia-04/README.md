# Día 4: Modelos de lenguaje (LLMs)

Cuarto día. Vemos cómo funcionan los modelos de lenguaje extensos por dentro y cómo usarlos como herramienta de investigación desde R, con `ellmer` y `quallmer`.

## Sesiones

| Archivo | Sesión |
|---------|--------|
| `13-entendiendo-llms.qmd` | 4.1 Entendiendo los LLMs: transformers, embeddings y atención |
| `14-llms-investigacion.qmd` | 4.2 LLMs como herramientas de investigación: prompt engineering, RAG y APIs |
| `15-laboratorio-07.qmd` | 4.3 Laboratorio 7: primeros pasos con `ellmer` |
| `16-laboratorio-08.qmd` | 4.4 Laboratorio 8: codificación cualitativa y confiabilidad con LLMs |

## Archivos

- `NN-*.qmd`: diapositivas de cada sesión (la numeración es continua a lo largo del curso)
- `laboratorio-N.R`: el código del laboratorio N en un script de R
- `tarea-N.qmd` y `tarea-N-respuestas.qmd`: enunciado y clave de respuestas de la tarea N
- `datos/`: conjuntos de datos usados en las sesiones y los laboratorios

Las diapositivas renderizadas están en el [sitio del curso](https://danilofreire.github.io/introduccion-ia-ucu).
