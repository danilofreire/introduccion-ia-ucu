1 Instrucciones

Esta tarea aplica los conceptos del Laboratorio 7. Responder cada pregunta escribiendo código R en los bloques indicados. Cuando se pida una respuesta escrita, usar texto normal debajo del bloque de código.

Para trabajar en esta tarea:

  1. Descarguen este archivo .qmd y el dataset textos_politicos.csv (en clases/dia-04/datos/) de la página del curso, o clonen el repositorio completo con git clone https://github.com/danilofreire/introduccion-ia-ucu.git
  2. Necesitan Quarto instalado junto con RStudio. Las versiones recientes de RStudio (>= 2022.07) ya incluyen Quarto
  3. Necesitan una API key de OpenRouter configurada como OPENROUTER_API_KEY en .Renviron. Alternativa: instalar Ollama y usar chat_ollama() en lugar de chat_openrouter()
  4. Abrir este archivo .qmd en RStudio y ejecutar los bloques de código con Ctrl+Enter (Cmd+Enter en Mac)
